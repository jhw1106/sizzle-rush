Sizzle Rush is a fast-paced 2D cooking game: run a tiny kitchen, take orders from the board, chop and grill ingredients, assemble dishes on the plate and serve them before the timer runs out. Playable with keyboard (WASD/arrows + E) and mouse, with synthesized sounds and a 150-second dinner rush.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
